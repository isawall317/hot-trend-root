## 对比维度（计划）

每款工具从以下维度对比：

1. **基本信息** — 名称、厂商、类型(CLI/IDE/桌面/插件)、官网
2. **价格** — 免费额度、付费套餐、Coding Plan 关系
3. **模型集成** — 支持哪些模型（自有 + 三方）
4. **核心功能** — Agent 模式、多文件编辑、MCP、Git 集成、终端集成
5. **平台** — Mac/Windows/Linux/Web/VS Code/JetBrains
6. **特色** — 独有能力
7. **适用场景** — 最适合什么类型的开发
