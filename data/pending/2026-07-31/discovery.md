### 需求三角形
- **缺乏感（强烈且官方背书）**: Anthropic 自己删 80% skills = 痛点被产品方确认。重度用户手上几十个 skills，找不到、记不住、不知道哪些过期、不知道哪些在烧钱。"工具越多越失控"是真痛点，不是锦上添花。
- **目标物（清晰）**: 一个 Claude Code 的"skills 卫生工具"——回答三个问题：①我装的哪些 skills 还在用？②哪些过期该删？③哪些在偷偷烧钱？附加：打包好的垂直套件（买来即用，不用自己组装）。
- **消费能力（中-强）**: Claude Code 重度用户是高净值群体，¥99-299/年可接受。

### 关键定位演进（对 ccskills-market 的两次修正）

| 时间 | 定位 | 证据强度 |
|------|------|---------|
| 7-24 | "个人 Skills 目录+检索+版本管理" | 4 条 |
| 7-31 首轮 | "从市场转套件"（卖打包好的职业方案） | 50 条样本 |
| **7-31 重扫** | **"Skills 卫生工具 + 垂直套件"**（先解决治理痛点，再卖套件） | 10+ 条 + 官方删 skills |

> **今日最锐利的判断**：ccskills-market 的核心卖点不是"存放"，是"治理"。**先做"skills 卫生"（扫描过期/检测烧钱/清理）这个高频痛点入口，再在上面开"垂直套件商店"**。顺序很重要——治理是入口（拉新），套件是变现（ARPU）。

### MVP 形态（两段式）
**第一段（MVP，2-3 周可做）**：输入你的 `.claude/skills/` 目录 → 扫描每个 skill 的：最后修改时间、是否引用已废弃 API、近 30 天是否被触发、估计 token 消耗 → 输出"skills 卫生报告"（哪些该删、哪些过期、哪些烧钱）。免费引流。

**第二段（变现）**：在卫生报告之上开"套件商店"——打包好的职业套件（公众号内容虾、盯盘虾、家教虾…），¥99-199/套。你的 7000 粉公众号 = 第一个套件的种子用户 + 分发渠道。

### 变现路径
- 卫生工具免费（拉新）→ 套件付费（变现）→ 套件订阅 ¥99/年（ARPU）
- 你的公众号就是内容虾的第一个真实用户 + 分发渠道

### 风险
- Claude Code 国内用户基数仍有限（但重度用户高净值，你在圈内）
- "skills 卫生"需要持续跟 Anthropic 更新（A 社删 skills 说明规则在变）——但这也是壁垒

- **目标物（清晰）**: 一稿输入 → AI 适配各平台格式 + 规则检查 + 封号预警。
- **消费能力（中）**: 自媒体创作者有付费习惯，¥39-99/月可接受。

### 与 7-24 的关系
7-24 信号 2 是"AI 配图"（6/10），今天这个是"分发"——同属创作者工具链，但环节不同。今天"ChatGPT 封杀令"这个**具体政策事件**把"防封+合规分发"抬到 6 分边缘。

### MVP 形态
