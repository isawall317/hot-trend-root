# 故事板：勇气 — 那一跳

## 角色

### 小宇（主角）
- 8 岁男孩，齐耳短发，戴蓝色泳镜（推在额头上）
- 偏瘦，穿白底蓝条纹泳裤
- 表情细腻：犹豫、紧张、坚定——主要靠眼睛和眉毛传达

### 教练
- 中年男性，平头，戴哨子
- 沉稳、不动声色，是小宇的"压力来源"也是"安全锚"

### 同学群（3-4 人）
- 各种肤色/发型，站在跳台下等待
- 笑脸、起哄、做鬼脸

### 哥哥（闪回中）
- 15 岁少年，与小宇有相似的眉眼
- 出现于第 4 页金色闪回中

---

## 第 1 页 — 起点

**画面**（4 格）

| 格 | 内容 | 对话/音效 |
|----|------|----------|
| 1.1 | 远景：夏日游泳馆全景，阳光强烈，泳池反光刺眼 | 音效：蝉鸣 |
| 1.2 | 中景：跳水区，5 米跳台高耸入画，背景是湛蓝天空 | 无 |
| 1.3 | 中近景：小宇站在跳水队伍最末尾，手攥着泳镜带子 | 内心独白：「好高……」 |
| 1.4 | 特写：小宇抬头的眼睛，倒映出跳台的剪影 | 内心独白：「这次一定要跳。」 |

色调：明亮、清新、带着期待的蓝。
视觉钩子：跳台占据画面右侧 1/3，形成视觉压迫。

---

## 第 2 页 — 恐惧

**画面**（4 格）

| 格 | 内容 | 对话/音效 |
|----|------|----------|
| 2.1 | 主观视角：小宇的眼睛所见——从跳台边缘向下看，泳池变得很小 | 无 |
| 2.2 | 极端俯视：水面、池底瓷砖、几个小黑点（人） | 音效：心跳 "咚……咚……" |
| 2.3 | 中景：小宇一步步走上跳台楼梯，腿微微发抖，扶手上有汗 | 无 |
| 2.4 | 特写：小宇的手指节发白地抓着扶手 | 内心独白：「要是没接住怎么办？」 |

色调：冷蓝压倒暖色，水面开始有阴影。
视觉钩子：极端高度差形成的眩晕感。

---

## 第 3 页 — 退缩

**画面**（4 格）

| 格 | 内容 | 对话/音效 |
|----|------|----------|
| 3.1 | 中景：小宇终于站到跳台边缘，前方是空白 | 无 |
| 3.2 | 中景：教练站在台下，平头，叉腰，抬头看着他，吹哨 | 教练：「小宇——下一个。」 |
| 3.3 | 中景：台下同学们挥手、起哄 | 同学：「小宇加油！」 |
| 3.4 | 近景：小宇一只脚不由自主地往后退半步，眼神躲闪 | 内心独白：「我做不到……」 |

色调：阴影开始爬上小宇的脸。
视觉钩子：教练和同学构成的"包围圈"形成心理压力。

---

## 第 4 页 — 回忆（金色闪回）

**画面**（4 格）

| 格 | 内容 | 对话/音效 |
|----|------|----------|
| 4.1 | 柔焦过渡：泳池变成金色滤镜，记忆开始 | 无 |
| 4.2 | 中景：去年夏天的浅水池，哥哥在水里朝小宇伸手 | 哥哥：「别怕，我接着你。」 |
| 4.3 | 近景：小宇（更小一号）憋气、捏鼻子，准备入水 | 无 |
| 4.4 | 中景：小宇扑进哥哥怀里，水花溅起，两人都笑得很开心 | 音效：「扑通！」+ 笑声 |

色调：**金黄色调** —— 与前 3 页冷蓝形成强烈对比。
视觉钩子：全页金色光晕，回忆的温度感。

---

## 第 5 页 — 决定

**画面**（4 格）

| 格 | 内容 | 对话/音效 |
|----|------|----------|
| 5.1 | 转场：金色褪去，回到当下。跳台边缘，小宇的侧脸 | 无 |
| 5.2 | 特写：小宇的眼睛，眼底还留着金色余温 | 无 |
| 5.3 | 特写：小宇深呼吸，胸口起伏 | 内心独白：「哥哥说——别怕。」 |
| 5.4 | 近景：小宇把泳镜拉下来盖住眼睛，攥拳，点头 | 无 |

色调：从冷蓝回到中性，但有金色残影。
视觉钩子：泳镜遮眼这个动作——"不再看，只感受"。

---

## 第 6 页 — 那一跳

**画面**（4 格，封面级大画面）

| 格 | 内容 | 对话/音效 |
|----|------|----------|
| 6.1 | 全页大跨页：小宇凌空跃出跳台，身体舒展，背景是巨大的蓝天 | 内心独白：「跳——」 |
| 6.2 | 中景：俯视角度，小宇的身体穿过金色的阳光带 | 音效：风声 "呼——" |
| 6.3 | 全页大跨页：入水瞬间，水花炸开成皇冠形，光线从水下透上来 | 音效：「扑——通！」 |
| 6.4 | 水下视角：小宇在水中睁眼，周围是透下来的金色光柱，蓝色 → 金色 | 内心独白：「我做到了。」 |

色调：**蓝光 → 金光** —— 全书最大的一次视觉转折。
视觉钩子：水下金色光柱，把"勇气"具象化。

---

## 全书视觉节奏

| 页 | 色调 | 张力 | 节奏 |
|----|------|------|------|
| 1 | 清新蓝 | 铺垫 | 慢 |
| 2 | 冷蓝压抑 | 上升 | 渐快 |
| 3 | 冷蓝 + 阴影 | 高点 | 紧绷 |
| 4 | 温暖金色 | 释放 | 缓 |
| 5 | 蓝金过渡 | 蓄势 | 慢 |
| 6 | 蓝 → 金 | 爆发 → 平静 | 极快 → 极慢 |

整本书的视觉张力曲线是 **^_^^**，3 是压力峰，4 是情感谷，6 是高潮释放。
