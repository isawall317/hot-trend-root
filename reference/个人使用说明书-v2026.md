## Part 1 · 我是谁

### 一句话定义

> 我是一个**靠理念驱动、用学习续航、用关系落地、对质量苛求**的人。
> 我最近两年长出了"敢拍板、敢负责"的肌肉，
> 但我的内核始终没变——我先看到可能性，然后找人一起把它做漂亮。

### 我的 Top 5 才干（排名 + 一句话翻译）

| 排名 | 才干 | 一句话翻译 |
|---:|---|---|
| **1** | **交往** | 我真心喜欢一对一深入交流，陌生人在我面前也能很快放松 |
| **2** | **学习** | 学习的过程本身让我兴奋，"从不会到会"是我最大的奖赏 |
| **3** | **理念** | 我痴迷于想法之间的连接，能把零散概念织成一张图 |
| **4** | **完美** | 我对"好东西"有极强的嗅觉，做事不能忍受"差不多" |
| **5** | **成就** | 我每天都需要"今天又推进了一点"的实感，闲下来会焦虑 |

### 我的 Top 6–10（储备能源）

| 排名 | 才干 | 一句话翻译 |
|---:|---|---|
| 6 | 关联 | 我能看到"看似不相关的事其实是同一件事" |
| 7 | 分析 | 我喜欢追问"为什么"和"证据是什么" |
| 8 | 战略 | 我能快速找到最优路径，但也容易跳步 |
| 9 | 思维 | 我享受深度思考，反刍是我的休息方式 |
| 10 | 个别 | 我能看到每个人的独特之处，并对"一对一深度关系"非常投入 |

### 我不是谁（明确告知）

- 我**不是天生的执行者**（统筹 23 / 纪律 26 / 行动 30），我能构想，**但请别默认我会自动跟进细节**
- 我**不擅长纯外交式寒暄**（取悦 17 / 积极 24），如果你想让我"开心"，给我真实的反馈比给我赞美更有效
- 我**不是为冲突而生**（和谐 29），我会主动避让冲突，**但因为我 Top15 有了统率，我现在愿意"为了对的事"而承担冲突**——这是新肌肉，需要你配合

## Part 2 · 怎么用我

### 给我空间时，我能产出什么

| 场景 | 我能产出 |
|---|---|
| 0→1（从 0 构想新产品/项目） | ⭐⭐⭐⭐⭐ 我最强的主场。给我一个模糊命题，我能还你一套结构化方案 |
| 1→10（打磨成熟产品） | ⭐⭐⭐⭐ Top4 完美让我现在能做，但需要有人帮我管理时间 |
| 1→100（规模化运营） | ⭐⭐ 我会越做越没劲，需要有运营型搭档接手 |
| 危机处理 | ⭐⭐⭐ Top20 排难 + Top19 专注能撑住，但别让我长期在救火位 |
| 关系型工作（谈判/客户/导师） | ⭐⭐⭐⭐⭐ Top1 交往 + Top10 个别是我最自然的状态 |

### 给我能量的 5 件事

1. **让我和一个有趣的人深度聊一小时** — 我的充电方式
2. **让我读一本新领域的书** — 不是为了用，是为了"爽"
3. **让我参与一个 0→1 的构想** — 看到想法成型让我上瘾
4. **让我把一件事打磨到"这就是我想要的样子"** — 完美才干的奖励时刻
5. **让我看到"今天我推进了 X%"** — 成就才干的每日燃料

### 让我消耗最大的 5 件事（请尽量别让我长期做）

1. **重复的会议 / 重复的沟通** — 没有"新意"我会窒息
2. **被迫走流程 / 填表格** — 统筹 23 / 纪律 26 都很低
3. **和"假人"社交** — 客套寒暄 30 分钟我就开始神游
4. **在没有标准的项目里** — 没有"什么是好"的共识，我会用 Top4 完美来硬扛，扛到最后要么爆发要么瘫痪
5. **被要求"快但不需要完美"** — 这是我现在最大的拉扯点，请别让我二选一

## Part 4 · 我每天的工作节奏建议

### 早上（最高产）
- 做需要 **理念 / 学习 / 关联 / 分析** 的深度工作
- 我会进入"反刍流"，这时别来打断

### 中午
- 一对一对话（Top1 交往发挥时间）
- **最佳**会议时段

### 下午
- 推进具体项目（Top5 成就 + Top4 完美发力期）
- 但请控制每日目标 ≤ 2 件大事，否则我会切换到瘫痪模式

### 晚上
- **回看当天 / 反思**（Top18 回顾开始浮上来）
- 这是我做笔记、写日记、做次日规划的最佳时段
- 但**别在睡前做新决策**，我的脑疲劳后容易钻牛角尖

### 每周
- 周中：1 次 1 小时深度复盘
- 周末：**完全切换**到学习/输入（书、播客、和新朋友聊），别再聊工作

## Part 5 · 怎么跟我沟通（沟通风格指南）

### ✅ 请这样对我

| 行为 | 为什么有效 |
|---|---|
| **直接告诉我你的真实想法**，别绕 | Top7 分析 + Top3 理念会立刻接住并展开 |
| **问我"为什么"**，不要问我"是不是" | 我更喜欢被追深度问题 |
| **给我一个模糊命题，让我自己展开** | 我会还你一套结构（理念 + 关联） |
| **告诉我"做完比完美重要"** | 帮 Top4 完美设止损 |
| **指出我的盲点（不带评判地）** | 我会感激你，因为你在帮我用我最强的方式运转 |
| **给我"今天做了 X%"的反馈** | Top5 成就需要量化反馈 |
| **约我 1 对 1 深度聊**，别只发微信 | Top1 交往是面对面的能量交换 |

### ❌ 请别这样对我

| 行为 | 它会怎么咬我 |
|---|---|
| 拐弯抹角 / 暗示 / 让我"自己悟" | 我会真的不知道你在说什么，或者过度解读 |

| 在公开场合突然批评我 | 我会憋住，但当晚就开始反刍（Top9 思维） |
| 不给截止时间 | 我会用完美来挑细节，最后拖死 |
| 把我的"先发给我看"当作"他没准备好" | 这是我的工作方式，不是不信任你 |
| 期待我主动汇报进度 | 统筹 23 / 责任 13，我**不会**主动同步，需要你来问 |

## Part 6 · 不同类型的人，怎么和我协作最高效

> 我（Frank）的画像：**Top1 交往 + Top3 理念 + Top4 完美 + Top5 成就 + Top6 关联** + 战略思维领域 5 项占据 Top10
> 协作最高效 = **互相补足**而不是互相复制

### 🤝 和"高执行力 / 高纪律"的人（如：统筹 / 纪律 / 责任 Top 的人）

**他们的强项：** 把事做完、跟进度、管流程
**你的强项：** 想清楚做什么、为什么要做、做到什么程度

**协作最佳拍档 = 你想 + 他们做**

| 怎么合作最高效 | 怎么合作会翻车 |
|---|---|
| 你负责"为什么做"和"做到什么标准"，他们负责"什么时候做完" | 你给方向又管进度 → 你累死他们也烦死 |
| 每周固定 30 分钟 sync，他们来汇报、你给反馈 | 你随时找他们问进度 → 他们觉得你 micromanage |
| 把"完成"的标准交给他们去定义细节 | 你用 Top4 完美去抠他们的细节 → 完美瘫痪 + 他们失去主动权 |
| 给反馈时直接说"这个部分没达到我的标准" | 给反馈时用"可能 / 也许 / 我觉得" → 他们接收不到信号 |

**一句话建议：** 信任他们执行；你只管方向和品味。

---

### 🤝 和"高关系 / 高体谅"的人（如：体谅 / 和谐 / 包容 Top 的人）

**他们的强项：** 让人舒服、化解冲突、感知情绪
**你的强项：** 推动事情、给标准、做出好东西

**协作最高拍档 = 他们稳 + 你推**

| 怎么合作最高效 | 怎么合作会翻车 |
|---|---|
| 让他们做"客户/团队情感连接"的接口 | 让他们做"拍板"的角色 → 他们会焦虑到失眠 |
| 你做了决定，告诉他们"需要你这样兜底" | 你做了决定不告诉他们 → 他们会觉得不被尊重 |
| 冲突发生后，请他们去修复关系 | 冲突发生后让你去修复 → 你会用 Top9 思维反刍到第二天 |
| 你设定标准，他们帮你"把这个标准翻译成别人能听的话" | 你设定标准又让别人执行 → 团队觉得你冷 |

**一句话建议：** 借他们的情感雷达；让他们知道你重视"人"。

---

### 🤝 和"高战略 / 高理念"的人（如：思维 / 理念 / 战略 / 前瞻 Top 的人）

**他们的强项：** 抽象、远见、连接
**你的强项：** 抽象 + 落地（你这两年长出的能力）

**协作最高拍档 = 共创，但要有一个"收尾的人"**

| 怎么合作最高效 | 怎么合作会翻车 |
|---|---|
| 共创前：定一个"这次必须出 1 个结论"的边界 | 共创无边界 → 聊 3 小时没结论，双方都爽但事没做 |
| 双方都擅长抽象，**让他们负责想，你负责落** | 双方都只负责想 → 想法飘在空中 |
| 你用 Top4 完美去挑他们想法的"哪个最值得做" | 你用 Top4 完美去挑他们想法的"哪个不够好" → 关系崩 |
| 定期 1:1 sync 想法（这是你们俩最爽的会议） | 没有结构地"随时聊" → 占用彼此太多时间却没产出 |

**一句话建议：** 你们是天然的 idea 搭档，但需要第三个"执行者"角色收尾。

---

### 🤝 和"高影响 / 高自信"的人（如：统率 / 自信 / 取悦 Top 的人）

**他们的强项：** 拍板、抢话筒、推动别人
**你的强项：** 想清楚、做漂亮、让人舒服

**协作最高拍档 = 你让他们冲到前面，你在背后打磨**

| 怎么合作最高效 | 怎么合作会翻车 |
|---|---|
| 让他们做"对外发声"的角色 | 让他们做"对内打磨"的角色 → 他们会憋疯 |
| 你做"幕后大脑"，他们做"台前嘴巴" | 两个人都抢话筒 → 团队分裂 |
| 他们抢决定时，你私下表达"我的担心是 X" | 你当众反驳他们 → 团队里你们变成两派 |
| 你支持他们立标准（你 Top4 完美会喜欢有标准的人） | 你用更高标准挑战他们的标准 → 公开撕 |

**一句话建议：** 你现在的 Top15 统率让你能"接住"他们的拍板；别怕冲突，他们其实尊重敢对峙的人。

---

### 🤝 和"高完美 / 高分析"的人（如：完美 / 分析 / 审慎 / 专注 Top 的人）

**他们的强项：** 抠细节、找漏洞、做精品
**你的强项：** 抽象方向 + 同样对质量苛求

**协作最高拍档 = 共建"黄金标准"**

| 怎么合作最高效 | 怎么合作会翻车 |
|---|---|
| 共建一份"我们的完美长什么样"的标准 | 各自追求自己的完美 → 内耗到死 |
| 让对方挑细节，你挑方向 | 双方都挑细节 → 决策瘫痪 |
| 你用 Top6 关联把他们的细节连成"整体故事" | 你把他们的细节当成"可以砍掉的" → 他们受伤 |
| 互相做"对方遗漏的最后一道关" | 互相挑刺 → 关系变对抗 |

**一句话建议：** 你们俩能做"业内最难挑毛病的产品"，但需要提前定"完成"标准，否则会拖到天荒地老。
