# 需求发现扫描 Prompt（加宽版 v2）

> 用法：`/discover` 与 `/discover` 周报模式下，读取 `discovery-input.json` 后按本 prompt 扫描。
> 替代 `SKILL.md` 里的旧 prompt。加宽了"可产品化"的定义，修复"输出全偏技术"的执行偏见。

---

## 核心修正：小软件 ≠ 技术软件

**"可产品化"不只指技术/开发者工具。** 下面这些方向都算可产品化的小软件 + AI 可撬动 + 睡后收入：

| 赛道 | 例子（不是新闻，是需求） |
|------|------------------------|
| 消费决策 | 到货提醒、比价、爆款追踪、看片/看书决策、避雷 |
| 生活工具 | 记账/习惯/打卡、家事管理、宠物健康、本地生活提醒 |
| 情感/社交 | 情绪记录、陪伴、关系分析、社群匹配、树洞 |
| 内容/创作 | 拆书/拆视频、字幕处理、图文生成、有声书、本地知识库 |
| 个人投资 | 盯盘/异动告警、财报解读、持仓体检（个人投资者向） |
| 学习/教育 | 错题本、出题、家教辅助、语言陪练、考研/考证追踪 |
| 健康/运动 | 健身动作库、体态纠正、经期/睡眠、饮食记录 |
| 工具型 SaaS | 自动化流水线、监控告警、数据采集、垂直 AI agent |

技术向工具只是其中一格。**每次扫描必须至少输出 2 个非技术向信号**（消费/生活/情感/内容/教育/健康类），否则视为筛选失败。

---

## 从"新闻/情绪"挖底层需求的方法

大众热点往往是"新闻本身"或"情绪宣泄"，不是直接的需求缺口。要往下挖一层：

- "女子月子期间遭丈夫施暴" → 新闻本身不可做；但底层需求是**家暴取证/庇护入口/法律援助导航**——可产品化
- "男子健身房被当众指控偷拍" → 情绪向；底层需求是**被诬陷维权/公共场所取证工具**
- "四川麻将明星联赛" → 娱乐；底层需求是**约牌/赛事报名/麻将记牌器**
- "豆瓣电影评分 8.2 奥德赛" → 消费；底层需求是**看片决策/烂片避雷/个人片单**
- "东北遭遇76年来最热夜" → 新闻；底层需求是**极端天气老人健康提醒/用电错峰**

**挖不动就跳过**——不是每条大众热点都有可产品化底层需求。宁可少输出，不要硬凑。

## 扫描 Prompt

```
你是 AI 利基发现助手。读取 discovery-input.json 中的 N 条热点（已按 source_type 均衡采样，
含 tech/news/social/content 多类），从中识别 3-5 个"可产品化的需求缺口"。

判断标准：
1. 不是新闻本身，而是新闻/讨论背后的需求（为什么这么多人关注？他们缺什么？）
2. 是否能用 AI + 小软件产品解决？注意："小软件"不等于"技术软件"——消费决策、生活工具、
   情感社交、内容创作、个人投资、学习教育、健康运动等方向都算。
3. 5-10h/周 + 睡后收入模式是否可行？
4. 国内可做、合规无雷区

强制约束：
- 每次输出至少 2 个非技术向信号（消费/生活/情感/内容/教育/健康/投资类）
- 大众热点要往下挖一层底层需求（家暴→取证工具、看片→片单决策），挖不动就跳过
- feasibility_score >= 6 才输出，宁缺毋滥

输出格式（JSON 数组）：
[{
  "signal_title": "一句话概括的需求（不是新闻标题）",
  "category": "tech|消费|生活|情感|内容|投资|教育|健康|工具",
  "evidence_count": 命中该需求的热点数,
  "evidence_examples": ["标题1", "标题2", "标题3"],
  "underlying_need": "底层需求（不是产品形态，是人们缺什么）",
  "target_user": "谁会付费",
  "ai_solution": "AI 能做什么、剩下要做什么",
  "mvp_shape": "MVP 大致形态（1-2 句话）",
  "feasibility_score": 1-10,
  "monetization": "可能的变现路径",
  "risks": ["风险1", "风险2"]
}]
```

## 与原 prompt 的差异

| 维度 | 原 prompt（SKILL.md） | v2（本文件） |
|------|---------------------|--------------|
| 可产品化定义 | 隐含偏向"AI + 技术产品" | 显式列出 8 个赛道，技术只占一格 |
| 赛道约束 | 无 | **强制至少 2 个非技术向信号** |
| 大众热点处理 | 无指引 | 显式教"挖底层需求"方法 + 例子 |
| category 字段 | 无 | 有，便于事后统计赛道分布 |
