# 样式布局整体优化方案

## 诊断

### 当前问题
1. **页面过长** — Hero → Quick Entries → Recommendations → Price Changes → Chart → Table → Articles → Community，8 个 section 堆叠，用户滚动疲劳
2. **图表孤立** — 一张大图夹在中间，没有上下文引导
3. **表格阅读体验差** — 列太多（14列），横向滚动，信息密度过高
4. **卡片层次单调** — 推荐卡片、快速入口、文章卡片风格不统一
5. **社群 CTA 在底部** — 最重要的转化点被埋在最下面
6. **移动端弱** — 表格在小屏基本不可用
7. **视觉节奏乱** — 间距不统一，section 之间没有呼吸感

### 优化方向

1. **信息架构重排** — 合并/拆分 section，按用户阅读路径组织
2. **表格优化** — 默认折叠关键列，移动端用卡片替代
3. **图表区重构** — 加入快速解读引导
4. **视觉层次** — 统一卡片风格，强化关键信息层级
5. **移动端** — 表格式→卡片式，导航适配
6. **CTA 上移** — 社群入口在页面前半段就有露出

---

## 实施计划

### Phase 1: 信息架构重排（核心）

```
新页面结构:
1. Hero（精简）
2. 快速入口 + 推荐卡片（合并为一个 "推荐" 区）
3. 图表 + 解读（数据洞察区）
4. 价格变动速报（保持）
5. 套餐对比表（折叠优化）
6. 最新测评
7. 社群 CTA（位置提前，样式强化）
```

### Phase 2: 表格优化

- 默认隐藏 `首月`、`月请求`、`1M Token价` 列
- 添加 "展开全部列" 按钮
- 移动端：表格改为卡片列表

### Phase 3: 视觉细节打磨

- 统一卡片圆角、阴影、hover 效果
- 加强 section 之间的视觉分隔（渐变分割线）
- 优化颜色对比度
- 优化字体大小层级

### Phase 4: 移动端适配

- 表格 → 卡片列表
- 导航汉堡菜单优化
- 图表高度自适应
- 推荐卡片单列排列

---

## 影响范围
